# Documentation Module

The Documentation module provides a centralized place to view module documentation in the Magento admin panel.

## Features

- View documentation from any module in **System → Documentation**
- Markdown rendering with GitHub Flavored Markdown support
- Hierarchical navigation with modules, features, and categories
- ACL-based access control for sensitive documentation

## Quick Start

To add documentation for your module:

1. Create markdown files in your module (e.g., `Docs/` folder)
2. Register them via `etc/documentation.xml`
3. Clear cache

See the **Registering Documentation** section for detailed instructions.
